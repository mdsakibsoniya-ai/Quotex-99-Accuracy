# patterns/README

This folder is reserved for the 96 pattern screenshots that will be provided separately as a ZIP file.

## Expected File Format
- `01_EURUSD_BUY.png`
- `02_EURUSD_SELL.png`
- `03_GBPUSD_BUY.png`
- ...
- `96_USDJPY_SELL.png`

## What is required inside each file
- clear candlestick pattern image
- market visible in the chart or file name
- action visible in the file name (BUY or SELL)
- 15-second candle style pattern

## Notes
- The developer must analyze these images for exact match logic
- The app should compare current charts with these reference patterns
- This folder may be filled later with the provided ZIP contents
